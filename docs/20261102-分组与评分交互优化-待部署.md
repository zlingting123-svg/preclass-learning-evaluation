# 分组与评分交互优化（待部署）

2026-11-02：本地代码与测试已完成，尚未更新云端。新 SSH 连接在 banner exchange 阶段持续超时，已有网页隧道仍可使用；没有切换云端版本。当前核对的前端入口为 `main-group-compact-20261102.js`（云端期间发生了并行更新，实际发布目录名尚未通过 SSH 核实），计划新版本 `20261102-group-score-simple`。

## 已实现

教师点击某组「评分」只显示该组的学生均分、教师评分输入与保存按钮，去掉弹窗搜索、轮次权重和其他组列表。顶部「教师评分」仍可通过小组下拉选择任意组；每组入口同时可用，支持修改已评分。0 分与暂无评分区分。保存失败保留输入。

删除原大面积评分卡片，教师统计保留为紧凑表格：小组、学生均分、教师均分、加权总分。保留姓名/学号/主题/组号搜索，评分明细按需展开；不删除既有小组或成绩。学生不展示教师统计表。

学生端顶部新增「学生互评」，其他小组行内新增「参与评分」。弹窗可选择其他小组、输入 0–100 分、保存或更新本轮评分；本组不参与互评。未入组、教师未开放、目标组未组队、待确认的组长转让等情况直接说明原因。

学生「编辑本组」可填写教师允许自定的主题。现任组长可从已关联的本组成员中选择接任者；保存发起转让，接任者在表格中点击接受后才更换组长。其他成员能编辑本组开放主题，不能直接夺取组长。保留教师指定主题、唯一入组、人数上限、版本冲突和本班权限限制。

## 禁用问题

原前后端使用「评分已开放 OR 本轮已有评分」锁定全部组队操作，导致刚开放、无人评分时学生也无法修改。本次将成员、主题、组长调整改为「本轮已有评分」才锁定；仅开放评分不再锁定这些操作。第一次评分与组队修改均在 SQLite 事务中检查。

已有评分后继续锁定组队，显示明确原因，学生仍可修改本轮互评分数；教师新建评分轮次可解除锁定，历史评分保留。教师重建整张分组计划仍需关闭评分。存在待确认的组长转让时阻止评分，避免首次评分锁死未确认申请。
