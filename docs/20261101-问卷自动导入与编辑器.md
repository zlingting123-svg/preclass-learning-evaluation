# 问卷自动导入与编辑器更新

已部署至 `/opt/preclass/releases/20261101-survey-builder`，产品版本仍为0.3。

导入Word后立即生成可编辑题目，识别单选、多选、填空、矩阵量表，以及数字题号、Word自动编号、字母选项和带题目/题型/选项列的表格。识别失败会报错；不明确的题型、重复/不足/空选项及无法归属的原文会标记问题，修正前不能保存或发布。支持查看原文、修正后重新识别和撤销本次导入。1MB大小限制，拒绝损坏、加密、无文字和有未处理修订的Word；支持有限的常见排版，不承诺任意Word都能无歧义识别。上传不调用付费模型或第三方服务。

原始《课前学生画像问题清单.docx》验证结果：18道原题，生成21个作答项；第7、8题识别为矩阵，共5+4个评分项目，评分1～5分；第14、15、16题“其他”保留选项并各增加一个选填补充输入。原文第4题未写明单选或多选，明确标记为待确认，其余题目自动生成。未注明必填的题目默认选填，教师可统一调整。

编辑器使用题目目录、当前题目编辑和学生端预览结构。选项数量始终可见，可逐项增删、排序或批量编辑；矩阵行与评分等级分别设置。保留问卷截止时间、限时、发布后锁定和版本冲突保护。学生端矩阵支持自动保存、恢复草稿和提交，教师端统计与只读答卷按评分项目展开，数据库原始题目与答案仍保留矩阵结构。

浏览器隔离验证覆盖原始Word上传、歧义阻止保存、修正题型、选项增删排序、矩阵预览、保存发布、矩阵作答草稿与提交，320/375/414/768宽度无页面横向溢出。另用正式服务器的实际静态资源重复通过；测试API均隔离，没有向正式班级写入模拟问卷或答卷。服务端内存数据库覆盖自动编号、Word表格、修订/坏文件拒绝、权限、校验、矩阵草稿/提交/统计/只读答卷以及版本冲突。真实手机操作、教师实际发布和300人并发作答仍需后续验收。

发布前执行现有备份服务，无SQL迁移。只修改两个后台模块及index，新增9个文件，其余3734个文件哈希保持一致；健康检查、三个服务和线上资源哈希通过。保留已部署的B版拼图、自定义点名、减速动画、签到计时、电脑签到码和登录自动填充。

上个版本为 `/opt/preclass/releases/20261101-puzzle-b`。本次新矩阵数据采用现有JSON存储：若用户已经保存矩阵问卷，不可直接切回不识别矩阵的旧前后端；应保留兼容模块修复或准备兼容回滚。不得恢复整库覆盖用户新记录。
