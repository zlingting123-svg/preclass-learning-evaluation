# 课程鲸鱼伙伴：形象与动作设计 v03（像素风）

2026-10-29。本轮是可交互设计稿，尚未替换正式主页或AI助手页面，也未重打包既有安装器。初稿使用下载的社区鲸鱼娘图集；用户指出碎片/裁断并要求像素风后，以原形象为参考重制像素姿态。等待用户确认视觉及动作后接入正式应用。

## 布局

主页：保留右侧卡片位置，用透明鲸鱼娘替换星光图标，形象+“和鲸鱼娘聊一聊”共同作为AI入口。桌面显示约192×208像素，卡片保持深绿配色；窄屏随卡片排到主内容下方。

助手：欢迎区靠右展示约160–192像素的伙伴。开始聊天后放在不遮挡消息的侧边留白内；窄屏缩为标题附近小形象，不覆盖输入框。第一版固定位置、可收起，避免拖动与复制/选择文本互相干扰。暂不做语音、自动行走或全站悬浮。

## 动作与触发

| 状态 | 表现 | 触发与结束 |
|---|---|---|
| 待机 | 像素眨眼、轻微呼吸 | 正常空闲；低频播放 |
| 欢迎 | 抬手挥手两次，约1.44秒 | 进入对话、主页入口悬停/键盘聚焦；随后回待机 |
| 思考 | 托腮姿态、轻微呼吸 | 仅实际请求pending期间；成功/失败/取消立即退出 |
| 回答完成 | 摊手姿态配轻微点头，约1.92秒 | 实际收到回答后；随后回待机 |
| 请求失败 | 静态关切表情+错误说明 | 网络或服务失败；由重试/清除错误退出 |
| 服务待接入 | 普通站姿+待接入说明 | 服务禁用或未配置；不播放思考动画 |

预览按钮“模拟发送”只做3.2秒思考→完成演示，不调用模型。预览本身明确标识“动作预览”；正式接入必须读取现有请求状态，不根据回复文字猜测，也不把前端计时当真正成功。

现成图集有跑步、坐下、哭泣和举字牌动作。课堂第一版选择挥手/思考/眨眼/呈现动作；举字牌内容与课程无关，跑步与频繁表情可能干扰阅读，先不加入默认循环。

## 实现备选

1. 推荐：透明WebP图集，按原始帧切换。体积约2.7MiB，本地打包，无远端热链，适合当前网页和安装包。
2. 后续：基于确认的形象另制课程专属动作帧，可加入翻书/记录等更贴合教学的动作，需要绘制并检查角色一致性。
3. Live2D/3D：交互更丰富，但需要额外模型与运行库，当前不作为第一版。

v01只编排现成帧；检查发现源图集部分姿态已包含残片和裁断，clip-path补丁也会削去角色。本轮v03改为参考原形象重制六姿态像素图集，以各格完整轮廓及透明留白为准，原始下载不改写。姿态顺序为睁眼待机、闭眼待机、挥手、思考、摊手、关切。轻微点头/呼吸使用整像素位移；不把姿态加位移描述为逐帧手部动画。

## 预览与接入检验

直接打开index.html，所有资源在本地，无CDN、无模型请求。动作可通过六个按钮手动切换，模拟发送可观察思考→完成→待机。系统开启减少动态效果时使用静态帧。

接入时检查：主页进入AI路由；推荐问题、历史会话、新建、删除/恢复、输入发送继续可用；请求成功/失败/取消/服务关闭状态正确；375px/768px/桌面布局不遮挡；减少动态效果、键盘焦点、收起后仍能重新展开。
