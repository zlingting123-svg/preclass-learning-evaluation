# 独立分组展示活动与评分权重对齐

2026-11-02，当前云端 `20261102-group-display`，上一版 `20261102-group-topics`。

教师评分权重改为与学生权重并排的同款数值框，上沿、高度和标签对齐。教师权重自动显示 `100 - 学生权重`，只读，继续通过“保存权重”提交。

## 新建与历史

- 顶部导出按钮前新增“＋ 新建分组展示”。输入展示名称，点击“创建并设置”，进入空白活动，设置主题、组数和人数上限后发布。
- 页面上方“分组展示”选择框可切换活动。每个活动分别保留主题、分组、成员、评分轮次、权重与评分；同一个学生可以在不同活动中分别组队，但同一活动只能加入一个组。
- 已有班级分组作为“原有分组展示”保留，无数据迁移、不覆盖已有成员和评分。
- 未发布活动只在教师端显示。学生只看到已发布活动，并通过原有表格自由组队。主题批量导入、统一大主题、组长接任、人数限制及评分锁定继续有效。
- 导出 Excel/Word 使用当前选择的活动，文件名带活动名称。

## 实现边界

新增 `group_activity` 记录。现有分组、评分通过 `activityId` 区分，设置/分组表按班级与活动组合键存放；缺少 activityId 的旧数据仍通过原接口使用。新增接口位于 `/api/v1/core/classes/:classId/group-activities`，活动内组队/评分/导出接口位于 `/:activityId/...`。所有请求检查角色、班级及活动范围，禁止跨活动编辑成员和评分。

活动创建请求用 UUID 防止同一请求重试重复创建。切换活动后重建表单和评分状态，异步响应限制在发起时的活动范围。活动列表和共享表格在页面可见时各每 5 秒刷新。
