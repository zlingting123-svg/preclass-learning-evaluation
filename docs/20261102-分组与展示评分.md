# 分组与展示评分

当前发布 20261102-groups，基于云端实际 20261102-citations，并保留其中的作业、课件、引用和桌宠等既有代码。本次未启用本地未发布的苹果风格改版。

师生导航新增分组与评分。学生可创建小组、编辑组长与组员、保存草稿或提交；组员可从名单选择或手动填写，唯一姓名自动关联，同名须选择账号。组长须为本班关联学生。教师可查看编辑所有小组、导出真实 XLSX/DOCX。

默认百分制，学生70%/教师30%，权重可调且合计100%。学生只能评价其他已提交小组，必须本人已加入已提交小组；每人每组每轮一个分数，更新覆盖本人原分数。学生、教师分别平均，再加权；正权重一方缺分时不显示总分。仅教师可查看全部评分明细与均分。

评分开放或本轮已有评分后锁定分组；教师关闭评分并新建轮次后可改组，原评分记录保留。当前导出/汇总针对当前轮次，暂未提供历史轮次查看界面。
