# 点名方式选择与姓名卡同步揭晓

点名设置增加“多人抽取方式”：逐个抽取、同时抽取。浏览器记住上次选择，单人抽取仍沿用原来的单人节奏。切换方式不发抽取请求，抽取中锁定设置。

逐个抽取保持一个抽取器、快速滚动后减速停顿，并将已揭晓姓名依次加入右侧名单；多人提速节奏保留。主显示区和右侧名单只显示姓名，移除学号。

同时抽取使用简洁姓名卡。卡片先显示待揭晓状态，准备、短暂停顿后全部同步翻开，卡片仅显示姓名。使用现有主题配色和中性边框，没有花色、扑克牌角标或纹样。普通模式约2.4～3秒完成一次揭晓，减少动态效果模式缩短等待。大批量卡片独立滚动，手机两列。支持全屏和直接揭晓。

随机结果仍由原服务端一次生成，前端只控制呈现方式。重试使用原请求ID，两种模式均不会额外抽取、改变结果或增加历史记录。后台学号、身份和班级数据保持，只调整点名界面的显示。

隔离浏览器验证覆盖逐个5人节奏、单人原节奏、右侧顺序、全屏、320/375/414/768宽度、同时5人先隐藏再同步翻面、翻转零错峰、切换不重抽、模式偏好、单人回退、人数校验、失败不伪造姓名且幂等重试、300人同时展示/滚动以及减少动态效果。测试使用模拟API，没有向正式班级写入模拟点名。候选和最终版本验证记录见JSON。
