# 作业评分与成绩表

2026-11-02 已更新云端，版本 `20261102-homework-grade`，上一版 `20261102-attendance-export`。

## 使用入口

教师进入「作业」→「查看作业与评分」，选择已发布作业，也可在作业列表点击查看提交。成绩表按名单顺序显示：学号、姓名、完成情况、分数、作业详情。支持姓名/学号搜索及未提交、待评分、待复核、已评分筛选。

点击「查看作业详情」可查看文字与附件，输入 0–100 分（支持一位小数）和选填评语，点击「保存评分」。成绩表提供「导出成绩 Excel」，无需等待截止；原截止后作业汇总导出和 ZIP 下载保留。未提交和未评分不计为 0 分；已评分的 0 分正常显示。学生只能查看自己的分数与评语。

评分对应具体提交版本。学生修改提交后，旧评分标为「待复核」，教师查看新版后重新评分。并发保存、提交版本变化会拒绝过期请求；每次重新评分保留历史。仅有对应班级权限的教师可以评分及导出全班成绩。

## 验证与范围

后台真实路由和内存 SQLite 验证通过：权限、班级隔离、分数边界和 0 分、未提交拒绝评分、版本冲突、评分历史、修改后复核、学生本人可见、XLSX 分数及名单顺序、原导出截止限制。

隔离页面及云端正式资源均通过浏览器模拟接口验证：评分和评语保存、五列表格搜索筛选、学生查看自己的成绩、重新提交/复核、附件预览后保留评分草稿，以及原拍照上传、材料内嵌、修改提交、课件刷新等流程。检查 320/375/414/768/1024/1440 宽度及移动端评分弹窗。正式资源验证不等于真实账号全流程验收；测试接口均被模拟，没有对真实学生作业打分。

测试浏览器关闭桌宠以避免它偶尔挡住课件刷新按钮；桌宠由另一位维护，本次未修改桌宠代码。

部署复制上版完整目录，仅替换后台 `homework.js` 和入口 HTML，增加 4 个前端资源；保留先前签到顺序与缺勤高亮、分组、学生首页等更新。服务健康及 HTTP 资源哈希已核对。无数据库结构迁移，无真实作业数据改写。

## 接续

补丁、构建/部署脚本、测试及前后快照见 `ops/server-patches/20261102-homework-grade/`。`build.mjs` 应在目标基线未部署本补丁前运行；已部署后重跑会因集成位置改变而停止。`deploy.py` 对上一版本和文件哈希有保护，不能直接重复部署。

后端评分 API：`PUT /api/v1/core/homework/:id/submissions/:studentId/grade`；成绩导出：`GET /api/v1/core/homework/:id/grade-excel`。评分记录存储在现有文档型 SQLite store 的 `homework_grade` / `homework_grade_history`。
