# 服务管理端

基于本地AI接入提交b48b080，任务分支feature/service-admin。用户进一步确认：管理端管理全站人员账户和服务器/API设置；课程知识、问卷详情、班级教学统计和教学导出保留在师生端。未把这些数据搬进管理页面。

## 使用

本机入口：`http://127.0.0.1:5174/admin/login`。专用管理员账号`service_admin`，随机强口令只在`backend/work/platform-sample/服务管理员账号.txt`，不在源代码、Git或网页响应中。原有师生账号和数据保留；已有admin角色同样受管理员权限控制。

快捷启动仍为`SAMPLE_BACKEND_PORT=3002 SAMPLE_FRONTEND_PORT=5174 python3 integration/sample.py start`，停止使用相同环境变量和stop。启动器依次构建AI包、后台、前端，显式初始化模拟库并执行幂等管理员初始化；已有管理员及口令不覆盖。单独初始化可在backend执行`DB_PATH=work/platform-sample/sample.sqlite npm run admin:bootstrap`（先build）。这是本机适配器，不能直接用于生产部署。

## 已实现

- 独立管理登录和路由：`/admin`、`/admin/accounts`、`/admin/api`、`/admin/server`、`/admin/usage`、`/admin/audit`。普通登录中的admin也转入管理端，预览和登录页提供管理入口。
- 账户：按账号/姓名/ID查找、角色筛选、分页、创建师生账户、修改姓名和师生角色、启停、重置密码、撤销全部旧登录、仅账户元数据CSV导出。密码重置后不能取回原密码。网页不能新增或升级管理员，受控CLI负责管理员创建；不能停用自己或移除最后一个可用管理员；不提供永久删除。
- 会话撤销：新增account_control版本，登录快照记录版本；每次认证校验版本和停用状态。更新、重置、撤销后旧会话立即失效，恢复账户不恢复旧会话；登录从user主记录读取最新角色。哈希期间管理员授权会重新核验。
- 服务器：维护模式即时拦截师生业务和登录，管理员仍可恢复；新登录会话时长1–24小时，已有会话不因此延长。设置存后台数据库，有版本冲突保护。
- API：每日次数、模拟预算、输出/排队/超时、主题隐私门槛、余额预警/停止值、多个供应商账户与共享并发组、学生/教师/系统用途、密钥环境变量名绑定。只允许AI_PROVIDER_前缀变量名，网页不接收原始Key或自定义上游URL，不回传变量值。
- API保存会更新当前模拟运行器，重启会从后台数据库恢复。存在reserved/calling请求时拒绝切换池，设置先严格校验，失败不部分保存；同一账户多Key不能增加共享额度。真实模式仍未启用，教师/系统池仅作预留；余额阈值仅保存，真实余额检查与通知渠道未接入。
- 用量查询只返回用户ID、调用时间、状态、用途、模型/账户、token及模拟计价元数据，不返回课程ID、问题、回答、问题指纹。操作日志只含操作者ID、操作、对象ID、时间，不含口令、密钥或教学内容。

## 接口

除`POST /api/v1/admin/login`外，以下全部需要现有Bearer会话且role=admin。服务端鉴权独立于前端守卫。

|接口|说明|
|---|---|
|GET /admin/overview|全站人员数量、维护状态与AI运行汇总，无课程数据|
|GET /admin/accounts|search、role、limit、cursor筛选分页；固定安全字段|
|POST /admin/accounts|username/displayName/role(student或teacher)/password|
|PATCH /admin/accounts/:id|displayName/role/disabled/expectedVersion|
|POST /admin/accounts/:id/password|password/expectedVersion；bcrypt；旧会话失效|
|POST /admin/accounts/:id/revoke|expectedVersion；旧会话失效|
|GET /admin/accounts/export|仅账户清单CSV，不含密码和教学数据|
|GET/PUT /admin/server|维护模式、后续登录时长及版本|
|GET/PUT /admin/api|模拟API设置、并发池、环境变量是否配置；保存需版本|
|GET /admin/usage|可按userId筛选，元数据分页|
|GET /admin/audit|操作元数据分页|

表内均省略`/api/v1`前缀；严格拒绝未知输入字段，不提供任意SQL、表名、文件系统、命令执行或教学数据查询接口。新增共享DTO在shared/admin.ts，不改变原0.4.0教学接口。
