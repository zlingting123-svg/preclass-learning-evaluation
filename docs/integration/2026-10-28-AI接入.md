## 接线

- `ai-module/`来自独立AI模块fc125e8的已跟踪源码，不包含原work、密钥或数据库。导出MockProvider/ModuleError供host适配；各自lockfile保留。backend通过`file:../ai-module`引用，先构建AI包再构建后台。
- `backend/src/ai.ts`复用现有LocalAuth令牌及Service.classAccess；每次提问、排队前后核验会话/角色/班级。客户端不能传身份、模型或Key；注销/撤销权限会阻止待处理调用。
- 本次课程scope对应classId。同班已发布`course_material`转为700字符片段，带来源标题/版本；草稿与他班资料不能参与。沿用词项覆盖基线，默认课程词为环境/环评，阈值来自mock配置。这不是语义RAG，不能保证抵御含课程词的混合越界问题；真实服务必须先完成课程规则和门槛标定。
- 复用预算预留、单用户并发、350模拟生成槽/600排队、幂等、断流取消和未知用量保守记录；多副本共享调度/账本仍待生产适配。
- 已有主页面Assistant和商业预览Chat通过同一个POST SSE客户端接线。保留预览原会话/复制/新建/停止布局，显示来源、模式、token用量和错误。问题独立检索，不发送历史，当前不支持依赖前文的追问；页面内存消息离开/刷新消失。
- 教师入口显示本班粗粒度提问方向及门槛，不开放学生提问池；问卷生成/统计解读仍返回AI_NOT_CONNECTED，由后续对应模型池实现。
- `/usage`只返回当前用户用量，`/topics/:classId`要求本班教师，`/admin`要求admin，仅给元数据与模拟账户容量。无正文/自由文本摘要持久化；账本在backend/work/platform-sample/ai，和主业务库分开。主库原备份命令不包含AI账本，需要关机后分别备份。

## HTTP约定

全部沿用`/api/v1`认证和标准错误信封；新增AI接口前缀`/core/ai`：

|接口|行为|
|---|---|
|GET /status|mode=mock/disabled；liveReady=false；historyStored=false|
|POST /chat/stream|`{classId,question,clientRequestId}`；SSE accepted/queued/sources/delta/done，或refusal/insufficient_evidence/error|
|POST /chat|兼容既有`{classId,messages,clientRequestId?}`；只处理最后一条用户问题，成功`{reply,sources,outcome,mode}`；旧客户端无幂等键时不能安全自动重试|
|GET /usage|当前用户累计调用/token/未知用量等|
|GET /topics/:classId|本班教师聚合计数，低于门槛不显示|
|GET /admin|管理员汇总、模拟账户并发状态，余额not_configured|

SSE HTTP200不等于回答成功，客户端必须见到done或明确拒答；error/断流不能当完整回答。重试沿用clientRequestId：已处理或未知用量的请求返回409，不自动重复生成。取消可能有已用量，不能假称免费。

## 本机运行

Node24.15+。依次在ai-module、backend、frontend执行`npm ci`，构建顺序相同。本机快捷命令：

```sh
SAMPLE_BACKEND_PORT=3002 SAMPLE_FRONTEND_PORT=5174 python3 integration/sample.py start
```

或双击`integration/打开AI接入版.command`。当前接入版主页面 `http://127.0.0.1:5174/`，同事商业预览 `http://127.0.0.1:5174/design-preview.html`，后台3002。默认命令仍使用原5173/3001，端口占用拒绝覆盖。停止同样的环境变量执行`sample.py stop`；只停止本目录进程，数据库和账号保留。

当前测试数据来自原本机模拟数据库的SQLite在线备份；原库只读、没有覆盖或升级，账号文件仅私密复制到新工作区work。新机器start会显式seed独立模拟库，不包含真实学生。认证口令仍只在backend/work/platform-sample/测试账号.txt。默认后台不设置AI_MODE则disabled，快捷启动仅设置mock；设置其他AI_MODE拒绝启动，绝不偷偷使用付费Key。
