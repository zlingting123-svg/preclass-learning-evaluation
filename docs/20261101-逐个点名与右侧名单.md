# 逐个点名与右侧名单

按用户截图反馈，把多人同时滚动改成单个抽取器逐个揭晓。桌面左侧保留一个抽取器，右侧按揭晓顺序累积同学姓名与学号，并显示已抽取人数；窄屏把名单放在抽取器下方，人数较多时名单独立滚动。

每位同学都经过快速滚动、逐渐减速、揭晓前停顿、显示结果的过程。第一位滚动约4.8秒，之后每位约3.4秒，每次揭晓后停留约0.85秒再继续。5人一轮约23秒。已揭晓的同学不再出现在当前滚动候选中；抽取期间锁定设置和重复抽取按钮。可直接揭晓剩余名单，该操作仅展示当前批次的结果，不发起新抽取。减少动态效果模式保留逐个展示并缩短等待。

服务端仍一次生成并记录该批次随机结果，前端只调整展示顺序；不改随机算法、候选权限、轮次不重复和请求幂等，不逐次另发请求，避免产生额外抽取和重复历史。切换班级或离开页面时停止旧的展示流程。全屏入口保留。

隔离浏览器验证：5人顺序从0→1→2→5，始终最多一个滚动位，右侧位置与顺序正确，只发一次抽取请求；先快后慢、停顿、上一位从滚动候选排除、抽取中设置禁用、全屏、320/375/414/768宽度、手机名单在下方、1/3/5/25人减少动画、300人直接揭晓、人数边界、请求失败重试复用原幂等ID均通过。API使用模拟班级，没有向正式测试班写入点名记录。正式静态资源另做同样验证。

发布基于当前问卷版本，只修改前端index并新增4个静态资源。保留B版拼图、Word自动导入、问卷编辑器和矩阵作答，以及签到计时、电脑签到码等已有功能。不改后台和数据库，不重启服务。当前发布目录与资源哈希以部署验证JSON为准。
