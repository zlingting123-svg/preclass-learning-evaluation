# 分组主题批量导入与统一大主题

2026-11-02，当前云端 `20261102-group-topics`，上一版 `20261102-group-board`。

教师在“分组与评分 → 编辑分组表”中新增两种快捷设置方式：

- **批量导入主题**：直接粘贴多行文字，或读取 TXT、CSV、XLSX、XLS 文件；读取后检查，点击“填入分组表”。TXT 每行一个主题，CSV/Excel 使用单列主题或数字序号加主题两列，Excel 读取第一张工作表。可带“主题”“分组主题”“小组主题”表头，序号列可带“序号”“编号”“题号”“小组”表头。
- **统一大主题**：输入一个主题，点击“应用到全部小组”，当前所有小组获得相同主题。

两种方式均可统一勾选“允许学生修改填入的主题”，默认关闭；各行仍可单独修改。批量填入前 N 组，后面已有主题不变；N 大于当前总数时自动增加小组总数，不缩减已有分组、不更改成员。应用操作只修改本地草稿，点击“发布分组表”才更新学生端。

文件大小上限 2 MB，一次最多 100 个主题，每个主题最多 200 字。超限、多余列、缺少主题等情况显示错误，保留当前分组表。TXT/CSV 支持 UTF-8，读取失败时尝试 GB18030。主题文件在浏览器读取，不上传原文件；发布时仍调用既有分组表接口，保留权限、人数、版本及评分锁定规则。

文件读取使用项目已有 SheetJS 0.20.3，按需加载；随资源与源码附 Apache 2.0 许可证。未安装依赖，没有改后端或数据库。
