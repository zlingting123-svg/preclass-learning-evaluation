# 签到导出、工作台与点名记录管理

发布 20261102-class-history 基于 20261102-groups，保留正在使用的定位签到、作业、课件、AI引用及桌宠。

签到记录新增最近N次与逐场勾选汇总，仅计算选中的已结束且未删除场次。后端校验每个场次的班级与状态；导出保留原有缺勤、定位提示和累计次数口径。

教师工作台加入课程课件、分组评分两张入口卡；学生首页补充问卷作业、课件和分组快捷入口。基于当前运行的teacher-workspace-homework-20261102.js追加，未用旧源码覆盖其他人的作业功能。

点名历史支持单条删除和一键清空，带确认；每次操作限定当前班级与当前教师，并传递确认时的记录ID快照，因此不会删除其他教师或确认后新产生的记录。记录使用独立删除标记，原始结果和幂等缓存保留；不会重置不重复点名的候选池。

前后端隔离验证及正式静态资源测试通过：选定场次/次数、累计次数读回、跨班和越权拒绝、取消/单条/批量删除、师生工作台、320/375/414/768布局。正式资源浏览器测试使用模拟接口，未删除真实记录。

变更2个后端文件及前端入口，新增7个静态资源，无数据结构迁移。新接口：POST /core/classes/:id/attendance-export、GET/DELETE /core/classes/:id/rollcall-records。
