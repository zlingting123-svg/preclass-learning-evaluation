# 教师评分入口与分组搜索

当前云端 20261102-teacher-grade，上版 20261102-student-home。学生工作台已先完成并保留。

教师在分组展示顶部可直接点击“教师评分”，无需先滚动到页面底部。有成员且已提交的小组操作栏增加“评分”，可定位到对应组。窗口可开放当前轮次评分，逐组录入0–100分并保存，显示当前账号已评分；空小组不列入可评分名单。开放评分会同时允许学生互评，界面有明确说明，沿用既有后端角色、版本、轮次和锁定规则。评分轮次变化会重建窗口，防止残留输入跨轮次使用。

班级分组表、下方评分结果卡片列表和教师评分窗口分别新增搜索，支持小组名、主题、姓名、学号和多个关键词组合。学号优先从成员信息读取，缺少时从有权限访问的本班名单关联。筛选只改变显示，清空恢复全部，评分结果与表格采用同一组序。编辑分组计划时暂不筛选，以保证输入主题对应原行，不错位保存。

浏览器隔离及正式资源验证通过：教师顶部/行内入口、开放与保存评分、0–100校验、错误提示及失败保留输入、空组排除、三处搜索、姓名/主题/学号/组合查询、原组序恢复、学生隐藏教师入口、320/375/414/768布局。测试使用模拟API，无真实评分写入。后端和数据库未修改，仅替换HTML入口、新增5个资源，无服务重启；健康和资源哈希检查通过。
