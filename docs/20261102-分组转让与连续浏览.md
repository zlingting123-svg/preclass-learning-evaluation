# 分组布局、组长转让与课件连续浏览

2026-11-02，当前云端 `20261102-group-reader`，上一版 `20261102-group-display`。

## 分组表

桌面表格采用固定比例列宽，主题和姓名可换行，操作列保持可见。表格容器宽度小于 740px 时，每组改为卡片排列，保留字段名称，不需要横向拖动。保留主题导入、统一大主题和独立活动。

组长可以选择本组其他已关联成员，点击“发起转让”。对方看到申请，可接受或拒绝；接受后才更换组长。发起人可撤回，教师可撤回待处理申请。学生不能在编辑小组表单或直接调用编辑接口时绕过确认更换组长；组长有其他已关联组员时，必须完成转让再退出。接收人退出、组长或相关成员被教师调整时，失效申请会清除。

转让按角色、班级、活动、小组、申请 ID 和小组版本校验；当前轮次有评分或评分开放时暂时锁定。存在待处理转让时不能开放评分，先确认或撤回。

## 课件浏览

课件标题旁增加醒目的“在线浏览”按钮，同一行顶端对齐。预览改为全屏连续滚动，保留上一页、下一页和页码跳转；当前页随滚动更新。支持 50%–300% 缩放和适合宽度。

搜索返回匹配页、次数和上下文，可直接点击结果或切换匹配页，自动滚到关键词位置并高亮。支持中英文、不区分大小写，并忽略文字间空白。没有文字层的扫描件会提示“没有可检索文字”，目前不自动 OCR。

继续使用受权限保护的逐页图片与校徽水印，不新增原文件下载。页面按可视范围加载，最多同时请求 2 张图片，缓存最近 8 页；长文档不会一打开就请求所有页面。横版、竖版和旋转页使用实际显示尺寸，搜索坐标按显示尺寸归一化。

## 后端与接口

- 新增 `group-transfer.js`，在原有及独立活动的 groups 路由下增加 `POST /:id/leader-transfer`、`/respond`、`/cancel`。转让申请嵌入小组记录，变更使用数据库事务和版本校验。
- 新增 `courseware-reader.js`。`GET /core/courseware/:id/reader-info` 返回各页实际显示尺寸；`GET /core/courseware/:id/search?q=...` 返回搜索结果与高亮区域。两个接口使用既有课件访问权限，响应 `private, no-store`。
- 使用服务器现有 Poppler 的 pdfinfo、pdftotext 提取尺寸与文字坐标，缓存位于课件自己的受保护目录，以原 PDF 大小、修改时间和页数校验。索引按需生成，未安装依赖。
- 既有图片接口增加 PNG 宽高，上传、转换、发布/撤回、课程证据索引与水印逻辑保留。

## 验证

- 后台在临时目录和内存数据库运行旧分组回归、独立活动隔离、转让权限/接受/拒绝/撤回/过期请求/退出清理/评分锁定。
- 使用合成 PDF 和真实 Poppler 验证中英文、空白与大小写、XML 实体、搜索位置、高亮坐标、横竖及旋转页尺寸、空白扫描件，以及课件权限和水印图片接口。
- 浏览器使用模拟师生 API，验证双方操作、表格在 320–1440px 无横向滚动且操作按钮可见；连续滚动、按需加载、搜索跳转/高亮、页码跳转、缩放、关闭恢复滚动、搜索结果换行和按钮对齐。无页面异常，图片请求并发峰值为 2。
- 部署后再用实际云端前端资源运行相同浏览器测试。测试不修改真实班级或课件数据。
