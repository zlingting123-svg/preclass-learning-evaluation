# 共享分组表与学生自由组队

2026-11-02，云端版本 `20261102-group-board`，上一版 `20261102-class-history`。

## 使用方式

1. 教师进入“分组与评分”，选择班级，填写小组总数、每组最多人数。
2. 表格逐行填写主题；留空允许学生自定。已填主题默认锁定，也可勾选“学生可改主题”。
3. 点击“发布分组表”。保存为草稿不会向尚未入组的学生开放。
4. 学生在同一模块查看主题、组长、成员及剩余名额，点击加入。每人同班只能加入一个组，换组前先退出；满员不可加入。
5. 第一位加入者默认为组长；组长退出时由下一位已关联成员接任。组员可补充允许自定的主题，组长可调整组名和组长。
6. 教师可编辑成员、调整主题及名额，或导出 Excel / Word。导出增加主题、人数和上限。

## 同步和数据规则

页面可见时每 5 秒刷新表格，操作成功后立即刷新。采用表格共享数据和定时更新，不是逐字实时协同文档。加入、退出和名额检查在同一数据库事务完成；旧版本主题、计划和小组编辑会提示冲突，重新获取后再操作。

保留原有班级分组、成员及评分。首次设置分组表会纳入已有小组；不能直接缩减掉有成员的小组，也不能把人数上限降低到现有人数以下。空小组缩减时归档。没有修改或清空生产班级数据。

评分开放或当前轮次已有评分时，分组暂时锁定。教师关闭评分并开始新轮次后再调整。学生不能评分本组，学生与教师分别取均分，按原可配置权重加权；默认学生 70%、教师 30%。
