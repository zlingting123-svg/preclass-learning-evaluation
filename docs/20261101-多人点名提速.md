# 多人点名动画提速

多人抽取的第一位滚动由4.8秒缩短到3秒，后续每位由3.4秒缩短到1.9秒，揭晓停留由0.85秒缩短到0.4秒。5人一轮约13秒，原约23秒。保留逐渐减速和350毫秒揭晓前停顿，右侧名单继续逐个加入。动画定时会在停顿边界唤醒，避免因为滚动间隔过长而跳过停顿。

单人抽取仍为4.8秒滚动与0.85秒揭晓停留。减少动态效果模式、直接揭晓剩余名单、服务端随机算法、历史和幂等保持。
