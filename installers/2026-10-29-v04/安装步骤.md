# Ubuntu24.04 x86_64首次安装

把tar.gz和同名.sha256文件传到已准备好的Ubuntu服务器同一目录，先校验，再解压到另一个空文件夹：

```bash
sha256sum -c preclass-ubuntu24-x64-ddc55257eccf.tar.gz.sha256
mkdir preclass-install
tar -xzf preclass-ubuntu24-x64-ddc55257eccf.tar.gz -C preclass-install
sudo bash preclass-install/install.sh --domain classroom.example.com --admin course_admin
```

将classroom.example.com替换成自己的正式域名。按终端提示输入两次管理员密码。不要把tar.gz、sha256或其他额外文件放入解压后的preclass-install目录，否则完整性检查会拒绝。可先执行 `bash preclass-install/install.sh --check` 只校验、不安装。

包含应用运行依赖、Node、Caddy和PDF wheel；基础Ubuntu依赖缺项时会通过apt安装。OS依赖齐全时可追加--offline。安装器遇到已有配置/数据库/current时会拒绝覆盖，不作为升级器使用。域名解析、必要备案及80/443防火墙先完成，HTTPS真实证书和公网访问还需检查。AI和搜索默认不启用。

可用 `sudo systemctl status preclass preclass-caddy` 查看服务，`sudo journalctl -u preclass -u preclass-caddy` 查看日志。定时完整备份会在备份期间暂停应用，应安排非教学时段。安装错误时保留数据，不擅自删除后重装。
