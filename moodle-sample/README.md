# Moodle 课前学习最小样板

这是能实际登录、保存画像草稿并提交文字作业的本地 Moodle 样板。全部师生、学号、班级和答卷均为模拟数据。

代码审阅入口：[草稿PR #2](https://github.com/zlingting123-svg/preclass-learning-evaluation/pull/2)，目标为尚未合并的依赖分支backend/oss-foundations（PR #1）。

## 直接打开

在已准备好的这台 Mac 上双击 **打开样板.command**，或在仓库根目录运行：

```sh
python3 moodle-sample/scripts/sample.py start
```

打开 <http://127.0.0.1:8873/local/preclass_sample/index.php>。模拟师生账号在本机 `work/private/演示账号.txt`，每次安装随机生成口令，不随 GitHub 上传。教师为 `teacher_a`、`teacher_b`；学生为 `001001`、`001002`、`002001`、`002002`。管理员凭据单独在 `work/private/credentials.json`，普通演示不需要管理员。

首次准备的前提是 **macOS Apple Silicon、Python 3.12+、Node.js** 和联网下载。脚本下载约240 MB压缩包/运行时，再解包并初始化实际 Moodle/PostgreSQL；不会全局安装软件或修改 shell 配置。当前已验证环境为 macOS arm64；Windows/Linux不能直接运行此便携启动器，插件可另装至满足 Moodle 要求的服务器，尚未做这些平台的运行验证。

```sh
python3 moodle-sample/scripts/sample.py status
python3 moodle-sample/scripts/sample.py verify
python3 moodle-sample/scripts/sample.py stop
```

停止也可双击 **停止样板.command**。停止只关闭样板进程，保留数据库和已保存内容；再次 start 继续已有数据。使用端口8873（网页）及55439（数据库），均只绑定127.0.0.1。请勿改绑公网或填入真实师生数据。测试会用模拟账号保存草稿和提交模拟作业，结果保留在本地数据库。

## 界面更新（2026-10-28）

登录及主要学生/教师页面使用“学习平台”名称。任务中心按实际课程和作业状态显示，支持课程和批次筛选；画像页有题目导航、填写进度、未保存提示和保存栏；教师可搜索和展开本班草稿。详细实现及验证见[界面设计](UI_DESIGN.md)和[本轮验证](verification/2026-10-28-ui.md)。旧截图与旧验证记录为历史证据。

## 建议查看顺序

1. 用学生 `001001` 登录：任务中心同时列出模拟秋季A班和下一春季课程，使用同一个账号跨期选课。
2. 打开“课前画像·试填草稿”：保留原始18题，来源已明确题型的7题可填并保存，另11题标注待确认。画像不算4次作业、不生成分数。
3. 打开“进入文字作答”：使用 Moodle 原生作业，保存草稿、提交，再重新打开确认。自动测试已提交 `001001` 的模拟作业，可用 `001002` 手动体验首次提交。
4. 退出，教师A登录：只列自己的课程，查看本班画像、导出本班CSV，进入 Moodle 作业反馈。教师B用于对照班级权限。

CSV文件保留学号原始字符串和前导零；Excel直接双击CSV可能把学号自动转为数值，应通过“从文本/CSV”导入并指定学号列为文本。导出对公式起始字符加保护。

## 最新来源与实现边界

- 实际安装 **Moodle 5.3+ (Build: 20261021)**，官方 stable503 包，含官方简体中文语言包；不改 Moodle 核心。
- 项目来源为 `origin/backend/oss-foundations@4e15d02`，共享契约v0.2.0；该最新任务分支仍是草稿PR #1，并未合并 main。main基线为c573fbe。本样板以它为基础新增独立目录，保留原React/Node系统。
- “学而思”按前文讨论的开源**学之思 xzs**理解，只参考任务组织与交互；没有复制其代码，没有启动第二套系统，也没有声称完成双系统集成。
- `plugin/`为新增 `local_preclass_sample` 插件。使用 Moodle 登录、会话、权限、数据库、锁和CSRF机制。画像是轻量自定义表单，未引入 SurveyJS，也未实现原Node接口适配或双库同步。
- 一个教学批次对应 Moodle 分类，一个教学班对应独立课程。课程上下文承担教师数据权限边界；分组辅助组织，不能单靠“分组”隔离编辑教师。
- 两位教师、两个班、四位模拟学生；两班各有第1次文字作业。第2—4次仅显示计划，没有伪造题目。文字作业设置不计数字成绩，正式评价体系尚待配置。
- 画像保留题型、必填、量表锚点未确认的事实，只开放明确的7题草稿。版本冲突返回409，保留本页有效输入，不能静默覆盖另一页保存结果。
- `fixtures/roster.csv`仅用于四行模拟导入，执行时核对指纹并复用既有模拟账号。**不等于实现了面向教师的500人名单预览、冲突确认和撤销产品**。原分支已有的CLI导入机制保留在原Node系统。

对照与后续选择见 [架构映射](MAPPING.md)。本轮实际检查见 [验证记录](verification/2026-10-27-local.md)。

## 运行时、授权和数据

下载来源、版本、大小和 SHA-256 保存在 `source.lock.json`。上游的 Moodle、中文包、PHP URL会滚动更新；如果与锁定哈希不符，脚本会停止，不会静默替换。以后刷新应保留旧缓存，核对官方版本、许可与兼容性，再显式更新锁文件并重跑验证。

这次本机便携 PHP 为8.4.1，属于旧补丁版本；PostgreSQL为18.4，分发包装版本含beta标记。它们只用于本地验证，不能据此宣称生产运行时安全或稳定。正式服务器需使用受维护的补丁版本、Web服务、HTTPS、备份和运维方案；本地PHP开发服务器不作为生产部署。

`work/`全部忽略上传，含 Moodle/运行时下载包、本地数据库、随机口令、会话、日志和答卷。不要提交其中任何文件。截图和验证JSON仅含模拟数据。公开仓库同步的是代码及证据，不会同步本地教学数据。
