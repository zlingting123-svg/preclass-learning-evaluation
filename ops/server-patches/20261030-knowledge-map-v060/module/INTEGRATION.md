# 主站0.3接入扩展

上游包knowledge-map-v0.6.0.tar.gz已独立校验（33个文件）。上游仅提供原稿预览，本次按用户要求扩展教师节点/层级编辑、原件不变的编辑版、学生只读、编辑版PDF、主站导航和同源postMessage账号衔接。

教师只编辑本人且有班级权限的图谱，按版本号防止覆盖；最多2000节点/40层，编辑版PDF最多100个根节点。XMind从主题结构本地提取，无AI调用；图片/PDF等可手动编排，不能冒称自动识别原稿全部节点。编辑版使用层级布局，不回写原XMind/SVG原件，也不是完整的XMind高级关系/样式编辑器。原件和原稿PDF保持独立下载。

嵌入主站时来源及window.source双校验，令牌仅同源消息和内存使用，不进入URL或存储；后端仍核验主系统身份和班级。界面继承主站主题。保留独立/knowledge-map/登录入口。兼容主系统班级items/nextCursor分页和旧数组。

依赖与0.5已安装环境完全相同，没有自动安装新依赖或自动调用真实收费模型。上游安装脚本未运行。正式安装及回退以项目outputs和GitHub部署报告为准，不能直接运行上游脚本覆盖其他电脑改动。
