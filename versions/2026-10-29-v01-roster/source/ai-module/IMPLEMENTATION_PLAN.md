# 独立AI/API第一版实施计划

用户已授权开始；本目录独立交付，不修改原系统。分步执行，不派并行代理。

1. 定义宿主鉴权/选课、知识库、模型适配与SSE契约；先写权限、拒答、幂等和隐私测试。
2. 实现SQLite元数据账本、原子额度预留/结算；未知上游费用保留预留，不假报零费用。
3. 实现仅RAM正文队列、用户并发限制、账户共享并发和用途池隔离、DeepSeek流式与余额适配器；无自动重新生成重试。
4. 接入已批准资料的检索接口。第一版内置明确标识的词项覆盖检索用于模拟验收，向量/语义检索通过KnowledgeProvider替换，不能将其得分称为语义概率。
5. 实现HTTP接口与安全失败行为；默认本机/替身，真实付费模式需显式打开、设定预算/价格/阈值并配置私密Key。
6. 实际构建/测试，200+模拟突发、持久文件正文泄漏扫描、断流/崩溃恢复、使用说明/接口/接续与交付包。

资料范围、真实课程相关度标定、真实上游调用与200人实网压测未获资料/额度配置前不宣称完成。生成结果依然受模型能力限制，范围门槛与系统提示不是事实正确性的证明。
