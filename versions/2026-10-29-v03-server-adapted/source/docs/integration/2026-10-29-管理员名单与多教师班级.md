# 管理员集中名单、首次改密与多教师班级

## 最新用户规则与入口

分支feature/admin-roster-onboarding基于a8f7e6e，仍使用用户指定的GitHub学习空间UI。管理员统一上传名单，依据“学号、姓名、班级”分班并建号；学生账号为学号，显示名为提供的真实姓名。教师端不再导入名单或自建班级，只选择管理员已建班级。用户明确同班可由多名教师共同选择；教师账号由管理员手动创建。

正确页面：http://127.0.0.1:5175/design-preview.html。管理员进入“服务管理 → 名单导入与分班”；创建教师使用“账户管理 → 创建师生账号”，角色选择教师。教师进入“添加已有班级”选择对应班级，已选择的班级不会被其他教师抢占。

## 管理员导入流程

1. 填写教学分组／学期标识。同一分组、同一班名复用同一个托管班级；新学期应使用新的分组，避免混入历史名单。
2. 上传CSV/XLSX/XLS/DOCX/DOC或粘贴文本。沿用已有受限文件解析；核对工作表、表头和三列映射。无表头使用表头行0，保留首行；不恢复源文件已经丢失的学号前导零。
3. 校验并预览。展示新增/复用账号和班级数、名单错误；姓名或角色冲突、学号身份冲突、科学计数法、同班重复学号均拒绝整批确认。预览不创建账号。
4. 填写统一初始密码（至少12字符、最多72字节），也可在页面生成临时密码。一键创建后新增学生各自使用独立bcrypt盐，后端只存哈希，不存/导出明文初始密码。管理员应事先记录并通过学校渠道发放，成功后页面清空密码输入。

本次为增量导入，不自动移除旧成员或历史班级。重复确认同一计划返回原收据；重导入会复用相同学号、保留已有密码和改密状态，不将个人新密码改回初始值。同一学生在多个班级或学期继续复用账号。身份不一致必须先核对，不能静默覆盖真实姓名。

导入计划绑定管理员、指纹、30分钟有效期；哈希计算在事务外，最终写入前重新验证管理员会话和名单。账号、身份、班级、选课、收据与审计同事务；失败无半批数据。完成后清除计划中的重复名单副本，仅保留重放元数据。大批量bcrypt需要等待；未做500人实际建号耗时验收，500行测试仅预览。进程在提交前重启会丢失未完成计算，重新预览/确认；已提交数据持久化。

## 首次登录与重置

新导入学生、新手工创建师生账号、管理员重置密码的账号均标记mustChangePassword。已有演示/历史账号不会被全站重置。

登录可获得受限会话，但服务端除本人信息、退出和改密接口外拒绝业务请求，返回403/PASSWORD_CHANGE_REQUIRED；前端进入专门改密页。新密码必须与当前密码不同，校验当前密码及两次新密码输入。成功后所有旧会话失效，需要使用新密码登录；不能通过修改前端状态绕过门禁。已有旧账号仍可正常使用，未要求全站强制重置。

受控旧CLI导入及历史内部导入助手也为新账号标记改密。教师HTTP名单写入和自建班级入口已关闭；旧内部方法保留历史测试/工具兼容，不作为新公开导入入口。

## 多教师班级

托管班级在管理员导入时就保存真实学生成员，可以尚无教师。教师目录只提供班级/分组/人数/已选教师及本人选择状态，认领前不包含学生学号或姓名。教师选择后获得该班教师权限；允许多名教师选择，重复选择幂等。

新增managed_class标记和class_teacher关系；统一Service.classAccess检查主教师或教师关系，所有课堂/问卷/AI授权复用此检查。ClassInfo新增teacherIds/teacherNames/batchName，旧teacherId只作为兼容字段：未选择时为空字符串，首次选择后保存第一位教师；不能再仅凭teacherId过滤其他教师的班级。

旧班级维持原归属和批次权限，不自动开放给全站。新教学分组为导入分组名称，不伪造旧cohort的课程、日期或计划人数。托管班级禁止学生通过旧加入码自行扩充名单。新管理视图仍不提供课程知识或学生AI对话正文。

## 契约0.5.0

| 方法/路径 | 作用 |
|---|---|
| POST /api/v1/admin/rosters/files/preview | 管理员受限文件解析，复用已有FilePreview |
| POST /api/v1/admin/rosters/preview | `{batchName,rows:[{studentNumber,displayName,className}]}`，返回计划/错误/计数 |
| POST /api/v1/admin/rosters/commit | `{planId,fingerprint,initialPassword}`，原子创建并返回收据 |
| GET /api/v1/admin/rosters/classes | 托管班级、人数和多名教师 |
| GET /api/v1/teacher/class-catalog | 教师可选班级与本人的claimed状态，不含学生信息 |
| POST /api/v1/teacher/classes/:id/claim | 严格空JSON`{}`；绑定当前已认证教师，允许共享 |
| PUT /api/v1/auth/password | `{currentPassword,newPassword}`；仅修改本人，成功后旧令牌全部失效 |

登录/Auth.me的User可含mustChangePassword:true。旧POST /teacher/classes返回403/ADMIN_CLASS_CREATION_REQUIRED；旧POST /core/classes/:id/roster/preview和commit返回403/ADMIN_ROSTER_REQUIRED。教师/core/files/preview仍供题目/课程文件识别，不写名单。
