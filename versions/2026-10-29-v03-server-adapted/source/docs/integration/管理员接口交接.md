# 独立管理员接口（2026-10-29）

入口：原登录页登录后管理员跳转 `/admin`；独立商业预览 `/design-preview.html` 登录管理员也进入管理中心。教师、学生仍使用原班级流程。新接口基址 `/api/v1/admin`，沿用既有Bearer认证和成功/失败信封，兼容既有0.4.0核心契约。

| 方法与路径 | 业务 |
|---|---|
| GET /overview | 账号、教师、学生、停用、班级、问卷、已提交答卷总数 |
| GET /users?q=&role=&page=1 | 按账号/姓名搜索与角色筛选，每页50条；返回items/total/page |
| POST /users | 创建teacher或student，字段username/displayName/role/password；不允许创建admin |
| PUT /users/:id | displayName/disabled/expectedVersion；用户名、学号与角色不开放修改 |
| POST /users/:id/reset-password | password/expectedVersion，更新哈希并使旧会话失效 |
| GET /classes | 全部班级与教师、成员数、cohortId及version |
| POST /classes | name/teacherId/expectedVersion=0，可选cohortId |
| PUT /classes/:id | name/teacherId/expectedVersion，可选authorizeCohort（默认false） |
| GET /classes/:id/members | 班级学生账号列表 |
| PUT/DELETE /classes/:id/members/:studentId | 添加/移出成员，保留账号和历史答卷 |
| GET /audit | 最近100条操作，包含操作人、动作、对象名称/ID和时间 |

账号DTO只含id/username/displayName/role/disabled/version，不返回口令、哈希或令牌。创建/重置密码至少12字符且bcrypt最多72字节；现有教师网页CSV导入的新学生默认密码策略保持原样，不混同于管理端手动创建。

服务器每次校验管理员角色及当前持久化角色。网页不可停用、改名、重置管理员或提权；管理员通过backend既有user:create本机工具维护，口令标准输入，不预置公共超级账号。本轮本机模拟管理员凭据仅保存在被忽略的work及用户本地交付文件，未上传GitHub。

停用及重置通过session_epoch撤销已有会话；恢复账号不会复活旧令牌。旧数据库记录省略epoch视为0，向后兼容。账号与身份表同步更新姓名；旧答卷中的姓名快照不回写，保留历史含义。

班级改名/换教师校验版本，旧授课教师立即失去该班访问权限。已有批次要求教师资格；管理员需明确勾选authorizeCohort才会新增教师到该批次，授权与班级调整/日志在同一事务。不会静默扩大教师权限到其他教师的班级。

写操作与审计日志同一事务，失败全部回滚。日志不包含密码、哈希或令牌。查询使用本地SQLite适配器；全局汇总为本地实现，不代表云端分页/性能或300人压测已通过。

已发现另有未合并的feature/student-conversations分支；本轮不自动合并或覆盖同事代码。后续合并时注意auth.ts会话撤销及预览入口的管理员分流，并重测会话和角色隔离。
