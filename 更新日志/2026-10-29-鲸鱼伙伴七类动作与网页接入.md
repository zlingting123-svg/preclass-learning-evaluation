# 鲸鱼伙伴七类动作与网页接入（2026-10-29）

按用户确认的像素风形象，完善七类动作并接入现有学习空间。正式网页只展示伙伴形象、正常提问与拖动交互，不增加形象设置、动作按钮或模型选择面板。

| 类别 | 表现与触发 |
|---|---|
| 待机 | 眨眼、轻微呼吸；问答空闲时陪伴 |
| 欢迎 | 主页间歇抬手问好、轻摆；点击形象进入提问；聊天页不播放 |
| 思考 | 托腮和思考点，仅当前问题实际请求期间播放；切换历史/新建不触发 |
| 回答完成 | 按持久化消息的成功终态（含范围/资料不足提示）播放摊手、短暂点头，约2.3秒后回待机；不表示答案正确 |
| 失败 | HTTP失败或持久化失败终态时关切、短暂摇头；取消回待机，不播放完成 |
| 服务待接入 | 根据已有/core/ai/status显示闭眼休息、慢呼吸；服务关闭时阻止发送模型请求 |
| 上下左右走动 | 根据拖动方向使用对应四帧步行，向上为背面；松手/取消捕获恢复当前业务状态 |

拖动有6px阈值，避免拖动结束误触主页跳转。移动范围限制在主页卡片或聊天内容区域，不覆盖聊天输入区。位置按比例存在本机localStorage，随窗口变更约束；可用键盘方向键移动。移动端支持pointer capture触摸拖动。系统减少动态效果时关闭自动动画，但保留拖动能力。

新增WhaleCompanion.tsx与companion.css；main.tsx接入主页/Chat，不修改后台契约。6姿态和16步行帧使用本地资源，逐格透明边距检查通过；不按错误等分步长强行切图。素材来源、摘要和矩形见frontend/public/companion/README.md、assets.json。

开发期动作预览：/companion-motion-preview.html，仅供查看七类动作及拖动，无形象设置控件，不加入生产Rollup入口或正式路由。实际入口仍为/design-preview.html。

验证：前端类型检查和生产构建通过；新增7组真实隔离HTTP/SQLite浏览器检查通过（模拟AI、失败/服务关闭定点注入，非真实模型）。覆盖主页跳转、聊天无欢迎、推荐问题、思考→完成→待机、失败/取消、四向拖动/边界/松手恢复/本机记忆、新建/删除/历史、待接入不请求、375px和减少动态效果。pageErrors为空。现有学生界面5组、管理员5组浏览器回归通过；后台82/82通过。模拟移动宽度不等于真机，未做真实模型或云端验证。
